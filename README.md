👽 About the Project

Alien Simulator is a fictional web project designed as an interactive alien simulation experience.

The project creates the illusion of interacting with a system capable of simulating extraterrestrial activity, transmissions and unknown entities.

Everything presented by the simulator is fictional and created for entertainment and experimentation purposes.

The objective was to combine web development, interaction and storytelling to create an unusual and immersive digital experience.

🛸 THE EXPERIENCE

The interface is inspired by fictional secret laboratories and extraterrestrial research systems.

The visual concept combines:

🟢 Neon green interfaces
📡 Unknown transmissions
👽 Extraterrestrial entities
🛸 Classified experiments
💻 Futuristic computer systems
⚠️ Warning messages

The intention is to make the user feel as if they have accessed a classified alien research system.

🚀 Running the Project

Clone the repository:

git clone https://github.com/Namycoco/controlador.git


Enter the project:

cd controlador


Install the dependencies:

npm install


Start the application:

npm start


Then open the local address provided by the application in your browser.
